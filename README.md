# NEXTworks HUB

Mobile-first single-page hub for the NEXTworks ecosystem.

## Included
- `index.html` — full interface and service config
- `manifest.webmanifest` — PWA metadata
- `sw.js` — basic offline caching

## Edit service links
Open `index.html` and change each service `url:'#'` to the real URL.

## GitHub Pages
Upload all files to the root of a GitHub repository and enable **Settings → Pages → Deploy from branch → main / root**.
